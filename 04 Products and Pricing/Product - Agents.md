# Product - Agents

> [!summary] Summary
> - AI agent orchestration platform inside the execution layer: specialist agents plan and execute in parallel.
> - Each agent has an autonomy level (Watch, Suggest, Execute) with budgets and least-privilege access per workflow.
> - Bring agents from any framework, low-code builder, or custom code; they inherit routing, policy, validation and audit without a rebuild.
> - Source: https://createos.sh/products/agents

## Overview

- **Title:** CreateOS Agents.
- CreateOS Agents is the AI agent orchestration platform inside the execution layer. Specialist agents plan and execute in parallel, each scoped to an autonomy level and checked against policy. Bring the agents you already build, or compose new ones.
- **CTAs:** book_a_demo -> https://cal.com/mrudul/connect-with-mrudul-createos?duration=30&layout=mobile · start_building -> https://createos.sh/app · product -> https://createos.sh/products
- The page also carries the shared CreateOS Skills banner; details in [[Products]].

## How CreateOS Agents work

| Step | What happens |
| --- | --- |
| Plan | Describe an outcome and CreateOS decomposes the work, or bring agents you already built. The plan is shown before anything runs. |
| Execute in parallel | Specialist agents run in parallel, each scoped to an autonomy level, each call routed through the governed path and checked against policy. |
| Approve and ship | Human approval gates fire where you set them. Approved work ships to your environment with a full audit trail. |

## What CreateOS Agents give you

| Capability | Detail |
| --- | --- |
| Multi-agent execution | Specialist agents plan and execute in parallel, instead of one model doing everything in sequence. |
| Autonomy controls | Set each agent to watch, suggest, or execute, with budgets and access scoped per workflow. |
| Policy on every call | Prompt-injection checks, policy validation, and human approval gates run before an agent acts. |
| Bring your own agents | Any framework, low-code builders, or fully custom agents inherit governance without a rebuild. |

## Autonomy levels

- **Levels:** Watch · Suggest · Execute
- Set the autonomy level per agent and per workflow, with budgets and least-privilege access. Bring agents from any framework, low-code builder, or your own code.
