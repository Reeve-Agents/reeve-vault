## One-line description of each competitor (from the pages)

- AWS Lambda MicroVMs: AWS's serverless Firecracker micro-VM service for running user and AI-generated code, generally available since June 2026.
- E2B: an open-source runtime for running AI-generated code in isolated sandboxes.
- Daytona: a pay-as-you-go runtime for AI sandboxes with fast spin-up.
- Modal: a serverless compute platform with a sandbox SKU and a strong GPU catalog.
- Vercel Sandbox: a sandbox tied to the Vercel deploy platform.
- Runloop: a devbox runtime aimed at long-running agent sessions.
- Cloudflare: container compute on Cloudflare's global edge network.
- Perplexity Sandbox (SPACE): the Firecracker-based runtime behind Perplexity Computer; developers reach it as a Python and bash sandbox tool inside the Agent API, with a standalone Sandbox API on the roadmap.
