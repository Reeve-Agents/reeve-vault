## Give every agent its own computer

CreateOS Sandbox runs each workload in a Firecracker micro-VM. Spin one up from the SDK, the CLI or MCP.

1. Its own kernel: a micro-VM, not a shared-kernel container, so a compromise inside one sandbox never reaches the host or another sandbox.
2. A private network: connect sandboxes to each other over a private network for multi-agent and multi-service workloads.
3. Outbound only: outbound egress runs through firewall rules and inbound ingress is closed, so a sandbox reaches out but nothing reaches in.
4. Pause and resume: pause an idle sandbox to stop paying for compute, then resume in place with its state preserved.
5. A disk that outlives the VM: sync the disk to Amazon S3, MinIO or Cloudflare R2, so the work persists after the sandbox is gone.
