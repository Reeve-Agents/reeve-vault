## Problems and solutions
The hub frames the offer as four "Built for" reasons.

| Reason | Detail |
|---|---|
| No vendor lock-in | Route to any model by task, cost, and latency, and swap providers without rebuilding. |
| Observability built in | Execution logs and metrics across every agent and workflow, so you can debug and improve. |
| Failover by default | A provider outage never takes your feature down. Routing fails over automatically. |
| Governance for customer-facing AI | Prompt-injection checks and output validation protect features that face real users. |

## FAQ
- **Which models can we use?** OpenAI, Claude, Mistral, Gemini, Meta AI, and more. Routing is model-agnostic, so you can switch without re-architecting.
- **What happens if a provider goes down?** Routing fails over automatically, so your feature stays up.
- **Can we monitor quality?** Yes. You get execution logs, metrics, and an audit trail across every workflow.
- **How fast can we integrate?** Start with a scoped pilot on one feature, then scale to your VPC or cloud.
