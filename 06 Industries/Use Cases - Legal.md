### Litigation document review

URL: https://createos.sh/industries/use-cases/litigation-document-review

- **Problem:** Associates spend nights reading thousands of pages to find the few that matter. The work is slow, expensive, and easy to get wrong under deadline.
- **Agent:** The agent reads each document, tags relevance and issues, and surfaces the passages that matter with a citation back to the source. A lawyer reviews before anything is relied on.
- **Outputs:** Relevance and issue tags; Cited source passages; Reviewer-ready summaries
- **Runs:** starts when a document set is produced or collected for a live matter. Mode: Suggest.

### Contract review and redlining

URL: https://createos.sh/industries/use-cases/contract-review-and-redlining

- **Problem:** Manual contract review is repetitive and inconsistent. Standard positions get missed, and turnaround slows every deal down.
- **Agent:** The agent compares each clause to your playbook, flags deviations, and drafts redlines with the reason for each change. Every edit is logged and a lawyer signs off.
- **Outputs:** Playbook deviation flags; Drafted redlines; Rationale for each change
- **Runs:** starts when a counterparty returns a marked-up draft for review. Mode: Suggest.

### Clause extraction and comparison

URL: https://createos.sh/industries/use-cases/clause-extraction-and-comparison

- **Problem:** Finding every indemnity, termination, or liability clause across hundreds of agreements by hand is slow and error-prone.
- **Agent:** The agent extracts the clauses you care about across the whole set and lays them out for comparison, each linked to its document and page.
- **Outputs:** Extracted clauses by type; Side-by-side comparison; Source links
- **Runs:** starts when a contract set is assembled for diligence or a portfolio review. Mode: Suggest.
