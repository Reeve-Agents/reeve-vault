## How an engagement works: The Production Path

A staged path from blank slate or stuck pilot to a decision and a build spec. Strategy-heavy up front, with a clear handoff to build.

| Stage | What happens |
| --- | --- |
| Discover | We run structured discovery across the business: current AI state, data maturity, security posture, and the pilots already in flight. Outputs include a use-case inventory and a clear diagnosis of what is blocking production. |
| Prove | We prioritize the highest-impact use case, score it against your own data and constraints, and produce a quantified business case and a build spec. The governance and security requirements are mapped before anything is built. |
| Productionize | For teams that proceed to build, forward-deployed engineers take the spec to governed production on the execution layer. Strategy and build are continuous, not handed off between teams. |
| Scale | The roadmap rolls forward. Each subsequent use case follows the same path: discovery, prioritization, build spec, and production, on the layer you keep. |
