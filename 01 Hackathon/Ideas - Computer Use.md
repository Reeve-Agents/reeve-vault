# Ideas - Computer Use

> [!summary] Summary
> - Category **Computer use: Agents that browse and click**. 3 ideas.
> - All 3 need the Beginner plan.
> - All use the `desktop:1` image (Chrome) with computer use: screenshots, clicks, typing and a live view in the browser.
> - Source: https://createos.sh/hackathon

## Accessibility auditor
- **Pitch:** Navigates your site keyboard-only in real Chrome, screenshots the problems, and writes a WCAG report with fixes.
- **For:** Companies that must meet accessibility rules, such as the EU Accessibility Act.
- **Sandbox feature:** Desktop and computer use. `desktop:1` has Chrome. The agent screenshots, clicks and types; you can watch it live in a browser.
- **With:** none named.
- **Plan:** **Needs Beginner plan.**

## New user onboarding tester
- **Pitch:** Signs up for your product as a stranger and notes every confusing step with screenshots, while you watch it live.
- **For:** PMs who never see their own signup flow the way a new user does.
- **Sandbox feature:** Desktop and live view link. Open the desktop's live view in a browser and watch the agent sign up in real time.
- **With:** none named.
- **Plan:** **Needs Beginner plan.**

## Docs screenshot refresher
- **Pitch:** Clicks through the app and regenerates every screenshot for the docs.
- **For:** Teams whose docs screenshots go stale after every UI change.
- **Sandbox feature:** Desktop and computer use. The agent drives Chrome in `desktop:1` and captures any screen, window or region as a screenshot.
- **With:** none named.
- **Plan:** **Needs Beginner plan.**
